Cómo reproducir

Todo el proyecto se regenera desde el PDF con los notebooks. Nada se hizo a mano en una planilla: otra persona, con el mismo PDF y el mismo código, obtiene los mismos archivos.

Requisitos

  • Python 3 (probado con 3.14).
  • poppler, que trae pdftotext y pdfinfo. Solo lo necesitan los notebooks 01, 02, 03 y 07.
    • Debian / Ubuntu: sudo apt install poppler-utils
    • Fedora: sudo dnf install poppler-utils
    • macOS: brew install poppler
    • Windows: descargar los binarios de poppler y agregarlos al PATH, o usar WSL.
  • Las bibliotecas de requirements.txt: pandas 2.3, numpy, pyarrow, matplotlib, scipy, jupyterlab, nbconvert.
¿Por qué pandas 2 y no 3?

Con pandas 3 el pipeline corre, pero las columnas de texto se graban en el Parquet como str en lugar de object, y el Parquet es la copia de referencia justamente porque conserva los tipos.

Instalación

# Linux / macOS
python -m venv .venv
.venv/bin/pip install -r requirements.txt

# Windows
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

El PDF

No está en el repositorio: pesa 43 MB y es una publicación pública. Hay que descargarlo del sitio del Consejo de la Magistratura y guardarlo como data/raw/anuario_2023.pdf:

curl -L -o data/raw/anuario_2023.pdf \
  https://magistratura.organojudicial.gob.bo/wp-content/uploads/2024/06/ANUARIO-ESTADISTICO-JUDICIAL-2023.pdf
sha256sum data/raw/anuario_2023.pdf
# 8b860105762a5987509c65aa4482b240fa21fde2e6e6ec5c0902022ac243f851

Si el hash no coincide, es otra edición o una descarga distinta, y las páginas pueden no corresponder. El notebook 01 verifica que tenga 774 páginas y capa de texto.

Correr los notebooks

Uno por uno, mirando

.venv/bin/jupyter lab

Abrir notebooks/ y ejecutar en orden. Los notebooks se ejecutan desde su propia carpeta: las rutas se calculan como Path.cwd().parent.

Todo de corrido

cd notebooks
for n in 01_diagnostico 02_inventario 03_extraccion 07_extraccion_procesos \
         04_normalizacion 05_validacion 06_export 08_integracion_interna \
         09_nulos_estados 10_indicadores_congestion 11_tratamiento_outliers \
         12_reporte_eda 13_verificacion; do
  ../.venv/bin/jupyter nbconvert --to notebook --execute --inplace $n.ipynb
done

La corrida completa tarda unos pocos minutos; el 07, que lee 525 páginas con coordenadas, es el más largo (unos 30 segundos).

El orden importa

El 07 corre antes del 04. Del 08 en adelante no hace falta el PDF: si data/processed/ está completo (lo está, porque se versiona), se puede empezar directamente en el 08.

Una corrida limpia desde cero

Borrar data/interim/ (no se versiona) y correr todo. Para forzar que el PDF se vuelva a leer basta con borrar data/interim/texto_crudo.txt. data/raw/ no se toca nunca.

Cómo saber que salió bien

  • El notebook 05 se detiene si falla un control técnico (geografía, juzgados, contexto, correcciones).
  • El 06 se detiene si una columna exportada no está documentada.
  • El 08 se detiene si una unión multiplica filas o si se modificó alguna tabla original.
  • El 10 se detiene si la suma de formas de ingreso no reproduce la identidad del Anuario.
  • El 13 termina con «bloques verificados: todo OK» o se detiene en la comprobación que falló.
  • Con git status, los CSV deberían quedar idénticos a los versionados. Los Parquet pueden cambiar en bytes si la versión de pyarrow es otra (la metadata graba la versión), sin cambios en los datos.

Extender el proyecto

A otros cuadros del Anuario

  1. Buscar el cuadro en auditoria/catalogo_cuadros.csv: página, título y primeras líneas.
  2. Mirar la forma real de la tabla: cuántas columnas, si hay celdas vacías, si los rótulos se parten o giran.
  3. Elegir la técnica: tokens si no hay huecos, posición si los hay, coordenadas si hay texto rotado o filas partidas.
  4. Declarar el orden de columnas y verificarlo aritméticamente contra el PDF. No reconstruir encabezados.
  5. Agregar la normalización en el 04, una identidad en el 05 y la descripción en el módulo diccionario (el 06 falla si falta).

A otra edición

Rehacer el 01 y el 02 (las páginas cambian), revisar las páginas declaradas en el 03 y las firmas de LAYOUTS_PROCESOS, y las reglas acotadas por página de las auditorías. Las trampas del documento probablemente se repitan.

Esta documentación

La web está en web/: HTML estático, un styles.css y un app.js, sin paso de compilación. Se publica tal cual en Netlify (netlify.toml). Para verla localmente hace falta un servidor, porque el buscador lee las páginas:

cd web && python -m http.server 8000
# abrir http://localhost:8000

El menú, el índice lateral y el buscador los arma app.js; para agregar una página hay que sumarla a la lista PAGINAS al principio de ese archivo.

Fuente: Consejo de la Magistratura de Bolivia, Anuario Estadístico Judicial 2023, Jefatura Nacional de Estudios Técnicos y Estadísticos. Los datos son públicos; este proyecto solo los tabula, verifica y analiza.
